🚀 NovaUI – Interactive Bootstrap 5 Website

NovaUI is a modern, colorful, and fully responsive multi-page website built using Bootstrap 5.
It includes a Home page, About page, and Contact page — all merged into a structured and animated professional UI system.

This project is designed to demonstrate strong frontend fundamentals including responsive layouts, UI components, animations, modals, icons, and interactive elements.
